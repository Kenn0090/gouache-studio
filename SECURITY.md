# Security

Please report a security problem privately: use **Security › Report a vulnerability** on the repository page, or contact the maintainer through GitHub ([@Kenn0090](https://github.com/Kenn0090)). Please do not post details in a public issue.

Gouache Studio runs on your computer. The optional features that talk to the network are update checks, content downloads (materials, skies, AI add-ons) and the local links to Blender, Unity, Unreal and Godot, which listen only on this computer and are off until used.
