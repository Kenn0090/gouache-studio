# Contributing to Gouache Studio

Thanks for taking an interest. Gouache Studio is a one-person project with AI coding assistants, so please keep changes small and talk first.

- **Found a bug or have an idea?** Open an issue using one of the templates. A project file or a short screen recording helps a lot.
- **Want to change code?** Open an issue first so we can agree on the approach. The source is in `src/js` (plain JavaScript, no framework); `CLAUDE.md` describes the layout, how to build, and the pitfalls we have hit.
- **Tests:** `tests/e2e` holds browser tests that check pixels. See `tests/e2e/README.md`. New features come with a test.
- **Releases** are made by the maintainer; see `AGENTS.md`. Please do not change version numbers.
- **Licence:** no open-source licence has been chosen yet. By sending a change you agree it may be used in the project; ask before reusing the code elsewhere.
