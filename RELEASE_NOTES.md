A smoother start, safer saving, and tools that remember themselves.

- **Welcome screen:** after a splash with the version, pick where to start (Paint, 3D Paint, Animation, Bake, Convert or Brush), open a recent file, or open an example. The cobblestone tile is now an example instead of opening at start-up.
- **Autosave:** every 5 minutes by default (Preferences: off to 30 minutes). If the app closes without saving, your work is offered back at the next start. Optionally autosave saves over the file itself.
- **Backups:** before saving over a file, the previous version is kept beside it as name.backup.gouache.
- **Recent files in the File menu:** Paint documents and 3D Paint projects, with their folders and when they were saved. The status bar shows where the current file is saved (click it to see it in Explorer).
- **Each tool keeps its own brush:** the brush, eraser, blend, dodge/burn, healing brush and clone stamp each remember their own settings. "All tools share the brush tip" keeps one tip for all of them.
- **Bigger brushes:** up to 5000 px, more in Preferences.
- **Fewer undo steps by default** (50) to avoid slowdowns and crashes with big documents. Change it in Preferences.
- **Shapes:** a corner bevel with segments like in 3D software (1 = a flat cut, more = rounder), rounding the whole shape like a pillow, and faceted height bevels.
- **3D Paint:** the mirror is in the 3D view's top bar; Stencils have their own tab next to Brushes; right-click a layer › Edit in the Paint canvas, then Send back to 3D Paint.
- **Keyboard shortcuts** in categories with search, and a warning when a key is already used.
