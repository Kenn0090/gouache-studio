The clone stamp.

- **Clone stamp (Y):** Alt+click where to copy from, then paint; the copy appears as you paint and is copied exactly (the healing brush blends it in instead). Opacity sets how strongly it covers; Aligned keeps the source moving with each stroke. It shares its source with the healing brush.
- On a material layer every map is copied together (colour, height, roughness…). It follows the selection, symmetry, and the mirror on the model in 3D Paint (Alt+click the model to set the source).
